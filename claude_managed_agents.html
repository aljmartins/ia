Claude Managed Agents

Ambiente gerenciado para rodar agentes autônomos na infraestrutura da Anthropic — sem construir loop, sandbox ou infraestrutura própria.

Fundamentos Como funciona
PASSO 01

Definir o agente

Configure o model, system prompt, ferramentas e servidores MCP. O agente recebe um ID único e pode ser reutilizado em múltiplas sessões.

system_prompt model tools mcp_servers agent_id
PASSO 02

Configurar o ambiente

Container cloud com pacotes pré-instalados, regras de rede e arquivos montados. Credenciais ficam no vault seguro — o agente nunca as vê diretamente.

Python / Node.js / Go network rules OAuth vault MCP proxy
PASSO 03

Lançar uma sessão

Sessão referencia o agente e o ambiente. Estado persistido fora da context window via session log. Recuperação automática após falhas.

session_id getEvents() context reset checkpointing
PASSO 04

Enviar mensagens

Claude executa ferramentas autonomamente em loop. Resultados chegam via server-sent events (SSE). Rastreamento completo no Claude Console.

SSE streaming tool_use loop Console tracing $0.08/hr runtime

Agente de suporte técnico

Lê tickets, pesquisa base de conhecimento e responde por email automaticamente

Modelo
claude-sonnet-4
System prompt
"Você é um agente de suporte. Leia o ticket, pesquise na base de conhecimento e redija uma resposta clara e empática. Feche o ticket ao concluir."
Ferramentas
Gmail MCP · Google Drive MCP · Web search
Ambiente
Python 3.12 · API interna de tickets
# Exemplo de chamada à API session = create_session( agent_id="agent_suporte_01", event={"ticket_id": "#4821"} )
Fluxo de execução

→
Busca na base

Redige resposta
→
Envia email
→
Fecha ticket

Recursos avançados O que o Managed Agents gerencia por você

🧠 Dreaming

O agente revisa sessões recentes enquanto "dorme", encontra padrões e atualiza sua memória automaticamente — como o cérebro humano durante o sono.

🎯 Outcomes

Defina critérios de sucesso e um agente avaliador verifica se o resultado foi atingido. Em testes internos, melhorou a taxa de sucesso em até 10 pontos.

🤝 Multi-agente

Um agente principal pode dividir tarefas complexas e delegar a subagentes em paralelo. Rastreamento passo a passo disponível no Claude Console.

🔐 Vault de credenciais

OAuth tokens ficam em vault seguro. O agente nunca manipula credenciais diretamente — um proxy autenticado faz as chamadas externas.

♻️ Context engineering

Sessões longas que excedem a context window são gerenciadas automaticamente via getEvents() e compactação, sem perda de contexto crítico.

📈 Escalabilidade

A infraestrutura ajusta automaticamente — o agente rode uma vez por dia ou mil vezes por hora. Você paga apenas pelo uso: modelo + $0,08/hora de runtime.
