02

Definir o agente

O agente é criado uma única vez e referenciado por ID — como um "template" reutilizável

Anatomia de um agente

O que você vai configurar

  • name — nome legível para identificar o agente no Console
  • model — qual modelo Claude vai usar (sonnet é o equilibrado)
  • system — o system prompt: define personalidade, regras e objetivo
  • tools — ferramentas disponíveis; agent_toolset_20260401 libera bash, arquivos, web search e mais

system prompt
"Você é um agente especializado em suporte técnico. Ao receber um ticket: leia o problema com atenção, pesquise soluções na base de conhecimento, redija uma resposta clara e empática, e registre a resolução. Sempre confirme se o usuário ficou satisfeito antes de fechar o ticket."
python — criar o agente
from anthropic import Anthropic

client = Anthropic()

# ✦ Passo central: criar o agente
agent = client.beta.agents.create(
    name="Agente de Suporte Técnico",
    model="claude-sonnet-4-6",
    system="""Você é um agente especializado em suporte técnico.
Ao receber um ticket:
1. Leia o problema com atenção
2. Pesquise soluções na base de conhecimento
3. Redija uma resposta clara e empática
4. Registre a resolução
Sempre confirme se o usuário ficou satisfeito.""",
    tools=[{"type": "agent_toolset_20260401"}]
)

# O ID retornado é permanente — guarde-o!
print(f"Agente criado com ID: {agent.id}")
print(f"Versão: {agent.version}")
Saída esperada
Agente criado com ID: agent_01HqR2k7vXbZ9mNpL3wYcT8f Versão: 1
ℹ️
Versionamento automáticoCada vez que você atualizar o agente (ex: mudar o system prompt), a Anthropic gera uma nova versão automaticamente. Os campos não alterados são preservados.

03

Criar o ambiente de execução

O ambiente é o container cloud onde o agente vai rodar — separado da definição do agente

Por que separar agente e ambiente?

Flexibilidade de configuração

  • Mesmo agente, ambientes diferentes — produção com rede restrita, dev com rede aberta
  • Pacotes pré-instalados — Python, Node.js, Go, ferramentas de sistema
  • Credenciais no vault — o agente nunca vê tokens; um proxy autenticado faz as chamadas
  • Arquivos montados — documentos, bases de conhecimento, configs

python — criar o ambiente
# Criar o ambiente de execução do agente
environment = client.beta.environments.create(
    name="ambiente-suporte-prod",
    config={
        "type": "cloud",
        "networking": {
            "type": "unrestricted"  # acesso à internet
        }
    }
)

print(f"Ambiente criado: {environment.id}")
Saída esperada
Ambiente criado: env_09XzP4mKqRt7nSvL2wUcB5e
⚠️
Networking em produçãoPara produção real, prefira "type": "restricted" e liste explicitamente os domínios permitidos. O unrestricted é prático para desenvolvimento e testes.

python — salvar IDs e lançar sessão
# ── Salvar em variáveis (ou num .env, banco, etc.) ──────────
AGENT_ID       = "agent_01HqR2k7vXbZ9mNpL3wYcT8f"
ENVIRONMENT_ID = "env_09XzP4mKqRt7nSvL2wUcB5e"

# ── Lançar uma sessão usando os IDs salvos ──────────────────
session = client.beta.sessions.create(
    agent_id=AGENT_ID,
    environment_id=ENVIRONMENT_ID
)

# ── Enviar o primeiro evento (mensagem do usuário) ──────────
with client.beta.sessions.events.stream(session.id) as stream:
    client.beta.sessions.events.send(
        session.id,
        events=[{
            "type": "user.message",
            "content": [{
                "type": "text",
                "text": "Ticket #4821: meu login não funciona desde ontem."
            }]
        }]
    )

    # ── Processar eventos em streaming ──────────────────────────
    for event in stream:
        if event.type == "agent.message":
            for block in event.content:
                print(block.text, end="")
        elif event.type == "agent.tool_use":
            print(f"\n[🔧 Usando ferramenta: {event.name}]")
        elif event.type == "session.status_idle":
            print("\n\n✅ Agente finalizou.")
            break

# O agente foi criado uma vez — use o ID salvo quantas vezes quiser
nova_sessao = client.beta.sessions.create(
    agent_id="agent_01HqR2k7vXbZ9mNpL3wYcT8f",   # mesmo agente
    environment_id="env_09XzP4mKqRt7nSvL2wUcB5e"  # mesmo ambiente
)
# Cada sessão é independente — estado zerado, contexto limpo
python — atualizar o system prompt (gera nova versão)
agent_atualizado = client.beta.agents.update(
    agent_id="agent_01HqR2k7vXbZ9mNpL3wYcT8f",
    version=1,   # versão atual (obrigatório)
    system="Novo system prompt com instruções atualizadas..."
    # campos omitidos são preservados automaticamente
)
print(f"Nova versão: {agent_atualizado.version}")  # → 2
