Large Language Model — passo a passo

O texto de entrada é dividido em tokens — pequenos pedaços de texto que podem ser palavras inteiras, partes de palavras ou pontuação. Um LLM não lê letras nem palavras completas: ele lê tokens. A frase média em português gera cerca de 1,3× seu número de palavras em tokens. Cada token tem um ID numérico no vocabulário do modelo.
~100.000 tokens no vocabulário BPE — Byte Pair Encoding Tokenizer Subword splitting
Cada token é mapeado para um vetor de números com milhares de dimensões — o chamado embedding. Esses números codificam o significado semântico do token. Palavras parecidas ficam próximas no espaço vetorial: "gato" e "felino" têm vetores semelhantes. Além do significado, o modelo soma um positional encoding para saber a posição de cada token na sequência.
4096+ dimensões Espaço semântico Positional encoding Matriz de embeddings
O mecanismo de atenção (self-attention) permite que cada token "consulte" todos os outros e decida quais são mais relevantes. São calculados três vetores para cada token: Query (o que estou buscando?), Key (o que ofereço?) e Value (qual informação passo?). O produto entre Q e K gera os pesos — "gato" presta muita atenção em "tapete" e "dormia" porque descrevem onde está e o que faz.
Query · Key · Value Multi-head attention Self-attention Softmax dos pesos
O transformer empilha dezenas ou centenas de camadas idênticas. Cada camada aplica atenção e uma rede neural simples (feed-forward), refinando progressivamente a compreensão do texto. As camadas iniciais captam sintaxe; as intermediárias, semântica; as finais, raciocínio e contexto longo. GPT-4, por exemplo, possui ~96 camadas; modelos menores podem ter 12–32.
Feed-forward network Layer normalization Residual connections 96+ camadas (GPT-4)
O vetor final é convertido em probabilidades para cada token do vocabulário (via softmax). O modelo seleciona o próximo token com base nessas probabilidades — a temperatura controla a criatividade (alta = mais aleatório, baixa = mais previsível). Esse token é adicionado ao contexto e o processo se repete até completar a resposta. É por isso que LLMs são chamados de modelos autoregressivos.
