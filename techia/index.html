O problema que o LLM sozinho não resolve

Modelos de linguagem são brilhantes — mas têm memória curta, conhecimento congelado no tempo e não têm acesso a sistemas externos. RAG e Agentes surgem exatamente para preencher essas lacunas.

Limitação 1

📅 Corte temporal

O modelo só conhece o mundo até a data de treinamento. Dados novos são invisíveis para ele.

Limitação 2

📁 Documentos privados

Não acessa sua empresa, seu banco de dados, sua documentação interna — a não ser que receba isso explicitamente.

Limitação 3

🔌 Nenhuma ação no mundo

O LLM puro só gera texto. Não executa código, não envia e-mails, não chama APIs por conta própria.

RAG — Retrieval-Augmented Generation

A técnica mais usada para dar memória de longo prazo e conhecimento atualizado a qualquer LLM, sem precisar re-treinar o modelo.

Intuição-chave: RAG é como dar ao modelo um "kit de pesquisa" antes de responder. Em vez de inventar, ele consulta — e só então fala.
Embedding

🔢 Transformar texto em vetor

Todo texto é convertido em um vetor numérico de alta dimensão. Textos semanticamente similares ficam "próximos" nesse espaço. É o que permite busca por significado, não por palavra-chave.

Vector Database

🗃️ Banco de dados vetorial

Armazena esses vetores e permite buscas por similaridade em milissegundos. Exemplos: Chroma, Pinecone, Weaviate, FAISS, pgvector.

Chunking

✂️ Divisão em pedaços

Documentos grandes são fragmentados em chunks de 200–1000 tokens. O tamanho ideal equilibra contexto suficiente com precisão da busca.

Reranking

📊 Re-ordenação dos chunks

Após a busca vetorial, um modelo secundário re-ordena os chunks pela relevância real à query. Reduz ruído e melhora muito a qualidade da resposta.

# RAG básico com LangChain + Chroma from langchain_community.vectorstores import Chroma from langchain_openai import OpenAIEmbeddings, ChatOpenAI from langchain.chains import RetrievalQA # 1. Criar embeddings e persistir no banco embeddings = OpenAIEmbeddings() vectordb = Chroma.from_documents( documents=chunks, # seus documentos já divididos embedding=embeddings, persist_directory="./db" ) # 2. Criar a cadeia RAG retriever = vectordb.as_retriever(search_kwargs={"k": 5}) llm = ChatOpenAI(model="gpt-4o", temperature=0) qa_chain = RetrievalQA.from_chain_type( llm=llm, retriever=retriever, return_source_documents=True ) # 3. Fazer uma pergunta result = qa_chain.invoke({"query": "Qual é a política de reembolso?"}) print(result["result"])

Agentes de IA — quando o modelo toma decisões

Um agente não apenas responde — ele planeja, age, observa o resultado e repete até atingir um objetivo. O LLM vira o cérebro de um sistema que interage com o mundo.

O loop ReAct: o padrão dominante para agentes. Reasoning + Acting — o modelo pensa em voz alta (chain of thought), chama uma ferramenta, observa o resultado e decide o próximo passo. Repete até terminar.
1

Thought — o modelo raciocina

O LLM analisa o objetivo e decide qual ferramenta usar e com quais parâmetros.

2

Action — executa a ferramenta

A ferramenta escolhida é invocada: uma busca, um cálculo, uma chamada de API.

3

Observation — vê o resultado

O output da ferramenta volta para o contexto do modelo.

4

Repeat ou Final Answer

O agente decide se precisa de mais ações ou se já tem resposta final para o usuário.

Agentic AI — sistemas que agem de forma autônoma

Agente é um padrão. Agentic AI é um sistema inteiro desenhado em torno desse padrão — com memória persistente, múltiplos agentes colaborando, capacidade de iniciar ações sem intervenção humana contínua.

Memória

🧠 Tipos de memória em agentes

In-context: o histórico da conversa atual.
External (Vector DB): memória de longo prazo pesquisável.
Entity memory: rastreia entidades mencionadas ao longo do tempo.

Human-in-the-loop

🛑 Controle humano

Sistemas agentic bem projetados permitem checkpoints onde um humano aprova ações críticas antes de executar. Crucial para segurança em automações reais.

Python — a língua franca da IA

Python não é apenas uma escolha — é o padrão da indústria. Todas as bibliotecas de IA de peso estão disponíveis em Python antes de qualquer outra linguagem.

O que ainda falta no mapa

Tecnologias essenciais do ecossistema moderno que completam o quadro — e que frequentemente ficam de fora das introduções básicas.

Function Calling

🔧 Tool Use / Function Calling

O mecanismo nativo de APIs como OpenAI e Anthropic para o LLM chamar funções definidas por você de forma estruturada. É a base técnica de qualquer agente — mais confiável que parsing de texto.

Observabilidade

📡 Tracing & Monitoring

Ferramentas como LangSmith, Helicone e Phoenix registram cada chamada, token consumido e decisão do agente. Impossível depurar sistemas complexos sem isso.

Prompt Engineering

✍️ Engenharia de Prompt

A habilidade de estruturar prompts com chain-of-thought, few-shot examples e system instructions claras. Determina 80% da qualidade do output.

MCP

🔌 Model Context Protocol

Padrão aberto da Anthropic (2024) para conectar LLMs a ferramentas e fontes de dados de forma padronizada. Está se tornando o "USB da IA" — conecta qualquer agente a qualquer ferramenta.

Fine-tuning

🎯 Fine-tuning vs RAG

RAG injeta conhecimento em tempo de consulta. Fine-tuning altera os pesos do modelo com exemplos específicos. Cada um tem seu lugar — não são substitutos.

Guardrails

🛡️ Guardrails & Avaliação

Sistemas como Guardrails AI e RAGAS validam se outputs são seguros, relevantes e corretos. Em produção, sem avaliação automatizada, você está voando às cegas.

Por onde começar — roteiro prático

Semana 1–2

🐍 Fundamentos Python + API

Aprenda a chamar a API da OpenAI ou Anthropic diretamente. Entenda tokens, system prompts e a estrutura messages[]. Faça seu primeiro chatbot.

Semana 3–4

🔍 Primeiro RAG com LangChain

Indexe um PDF com Chroma e embeddings. Faça perguntas sobre ele. Entenda chunking e os impactos de diferentes tamanhos.

Semana 5–6

🤖 Primeiro Agente

Crie um agente com LangChain que usa busca na web e calculadora. Veja o loop ReAct em ação. Use LangSmith para ver o trace.

Semana 7+

🚀 Sistema Agentic Completo

Monte um pipeline com CrewAI ou LangGraph com múltiplos agentes, memória persistente e avaliação com RAGAS.

Recurso essencial: python-dotenv para variáveis de ambiente + Jupyter para experimentar + LangSmith gratuito para ver o que acontece dentro do seu agente. Comece por aí.
