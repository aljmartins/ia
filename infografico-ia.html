Modelos que criam conteúdo novo — texto, imagens, código, áudio e vídeo — com qualidade próxima à humana. É a área de maior crescimento atualmente.

LLMs Imagens Código Áudio

ChatGPT / Claude — geração de texto
DALL·E / Midjourney — imagens
GitHub Copilot — geração de código
Suno / ElevenLabs — áudio e música
Sora / Runway — geração de vídeo
