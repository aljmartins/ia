01 — Diferenças fundamentais
AI Agent

Agente de IA

Um sistema de IA que percebe o ambiente, toma decisões e executa ações para atingir um objetivo. É a unidade básica de autonomia.

Escopo definido — atua dentro de um domínio específico com ferramentas pré-configuradas
Loop percepcão → decisão → ação — ciclo fechado e repetível
Pode ter memória de curto ou longo prazo para manter contexto
Usa ferramentas — APIs, buscas, código, bancos de dados
Responsabilidade única — geralmente executa um tipo de tarefa bem definido
Pode ser supervisionado por humano (Human-in-the-loop)
vs
Agentic AI

IA Agêntica

Um paradigma de sistemas onde múltiplos agentes colaboram de forma autônoma, planejam em longo prazo e se adaptam dinamicamente.

Escopo aberto — decompõe objetivos complexos em subtarefas em tempo real
Planejamento de longo prazo — raciocina sobre sequências de passos futuros
Orquestração de múltiplos agentes — coordena especialistas em paralelo
Autonomia elevada — opera com mínima intervenção humana por longos períodos
Auto-reflexão — avalia os próprios erros e ajusta a estratégia (ReAct, Reflexion)
Objetivos emergentes — pode decompor metas que não foram previstas explicitamente

03 — Exemplos práticos
AI Agent

Agente de busca e sumarização

Search + Summarize

Recebe uma pergunta, busca na web, lê páginas, filtra e entrega um resumo estruturado — tudo sem intervenção.

Exemplo real
Perplexity AI, ChatGPT com browsing, Claude com pesquisa web
AI Agent

Agente de código

Code Agent

Lê uma issue ou especificação, escreve código, roda testes, interpreta erros e itera até o código passar.

Exemplo real
GitHub Copilot Workspace, Devin, Claude Code, Cursor Agent
AI Agent

Agente de automação de dados

Data Agent

Conecta-se a bancos de dados, gera queries, analisa resultados e produz relatórios ou dashboards automaticamente.

Exemplo real
Julius AI, Pandas AI, agentes no Snowflake Cortex
Agentic AI

Pipeline de pesquisa autônoma

Research Pipeline

Dado um tema, decompõe em subtópicos, delega buscas a sub-agentes, sintetiza fontes e redige um relatório completo.

Exemplo real
OpenAI Deep Research, Gemini Deep Research, Claude Research
Agentic AI

Agente de desenvolvimento de software

Software Engineer Agent

Orquestra agentes de planejamento, codificação, revisão e QA para entregar uma feature completa a partir de uma descrição em linguagem natural.

Exemplo real
Devin (Cognition), SWE-Agent, AutoCodeRover
Agentic AI

Assistente pessoal autônomo

Personal AI OS

Gerencia e-mails, agenda reuniões, delega tarefas, monitora projetos e toma ações em nome do usuário durante horas sem supervisão.

Exemplo real
Rabbit R1, Operator (OpenAI), agentes no Zapier AI

Por que usar múltiplos agentes?

Sistemas agentic avançados decompõem tarefas complexas e delegam partes a agentes especializados que rodam em paralelo, depois consolidam os resultados.

⚡
Paralelismo — sub-agentes executam ao mesmo tempo, reduzindo latência total
🎯
Especialização — cada agente otimizado para sua tarefa (código, busca, análise)
🔄
Resiliência — se um sub-agente falha, o orquestrador pode redelegar ou tentar novamente
📏
Contexto longo eficiente — cada agente vê apenas o que precisa, sem encher o contexto do LLM
🛡️
Verificação cruzada — um agente crítico pode revisar o output de outro antes de entregá-lo
06 — Conceitos-chave
🛠️

Tool Use

Capacidade do agente de chamar APIs, executar código, fazer buscas ou manipular arquivos como "ferramentas".

🗺️

Planning

Decomposição de objetivos em passos menores e ordenação lógica de ações antes de executar.

💾

Memory

Memória de curto prazo (contexto da janela) e longo prazo (vetores, banco de dados, arquivos).

🔁

ReAct Loop

Padrão: Reason (raciocinar) + Act (agir). O agente alterna entre pensar e executar iterativamente.

🪞

Reflexion

O agente avalia seu próprio output, identifica erros e regenera a resposta com base na autocrítica.

👥

Human-in-the-loop

O agente pausa e pede aprovação humana antes de executar ações irreversíveis ou de alto risco.

🧩

MCP / Function Calling

Protocolos padronizados (como o Model Context Protocol) que definem como agentes se conectam a ferramentas e serviços externos.

🌐

Ambiente (Environment)

O "mundo" no qual o agente age — pode ser o navegador, sistema de arquivos, API externa, terminal ou outro agente.
